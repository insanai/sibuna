ACCESSIBILITY CHECKS
WCAG 2.2 SC 1.4.3 text contrast target: at least 4.5:1.
WCAG 2.2 SC 1.4.11 essential lines and arrowheads: at least 3:1.
Measured minimum text contrast: light 13.85:1; dark 11.61:1.
Measured minimum line contrast against adjacent fills: light 6.45:1; dark 4.96:1.
Calculations use unrounded ratios to pass/fail, not rounded displayed values.
Actions, decisions and outcomes have distinct shapes and explicit text labels.
Color is never the sole way to distinguish a branch or outcome.
SVGs have titles and descriptions; the README provides alt text and equivalent prose.
These checks cover the diagrams; they do not certify the whole project as WCAG compliant.
