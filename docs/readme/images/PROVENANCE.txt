ACCESSIBILITY CHECKS
WCAG 2.2 SC 1.4.3 text contrast target: at least 4.5:1.
WCAG 2.2 SC 1.4.11 essential lines and arrowheads: at least 3:1.
Measured minimum text contrast: light 13.85:1; dark 11.61:1.
Measured minimum line contrast against adjacent fills: light 6.45:1; dark 4.96:1.
Calculations use unrounded ratios to pass/fail, not rounded displayed values.
Actions, decisions and outcomes have distinct shapes and explicit text labels.
Color is never the sole way to distinguish a branch or outcome.
SVGs have titles and descriptions; the README provides alt text and equivalent prose.
These checks cover the diagrams; they do not certify the whole project as WCAG compliant.

SCREENSHOT PROVENANCE
console-globe-93225dc9.png and console-traffic-fba02476.png:
Captured 2026-10-17 from a release build of Rust revision b52ef5d (version
1.0.0-beta.2), on one SQLite node, in normal (headed) Google Chrome 155.0.8059.85.
The browser viewport was 1440 x 646, with the system dark theme and the console's
compact spacing. Browser full-page region captures preserve complete dashboard
sections (1440 x 1128 and 1440 x 1288 respectively): the request summary in
console-traffic-fba02476.png, and both complete globe /
timeline panels in console-globe-93225dc9.png. Navigation is retained in both images.
No CSS, interface content or counters were altered. Browser captures were
re-encoded as PNG without retouching or compositing.

All requests stayed on loopback. Eight Python HTTP clients sent roughly 90–160
requests per second to a forward-auth listener. The mix included allowed public
pages, challenged checkout requests, denied admin requests, SQL injection and XSS
queries. A local policy supplied four named rules. User-Agent and Referer fields
were synthetic. Live boot totals were selected; counts are illustrative, not
benchmark results or real visitor activity. The globe was centered on the
configured London server position (51.5, -0.12), with animation paused.

The build used SIBUNA_GEOIP_DATA with a synthetic nine-range snapshot produced by
geoip-snapshot --provider user-country --version 2026-10-17. Ranges 11.0.0.0/16
through 11.8.0.0/16 were assigned US, GB, DE, BR, ZA, IN, SG, JP and AU respectively.
These are test mappings, not actual geolocation, and no traffic was sent to those
public addresses: they appeared only in X-Forwarded-For on local requests.
The snapshot and disposable seed, account and SQLite state stayed outside the repo.
