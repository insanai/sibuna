{{ _("Internal gRPC services") }}

{{ _("Issue certificates for internal names with the local CA. Clients trust its root and call the service over TLS. An HTTP/2 backend carries gRPC messages and trailers.") }}

{{ _("A cluster of edge nodes") }}

{{ _("Distribute a checked routing configuration across the mesh. Nodes can share bans and learned affinity while each node forwards traffic to its own backend pools.") }}

{{ _("DDoS protection at the edge") }}

{{ _("We can cap concurrent flows per client IP and frontend, limit admission of new addresses under pressure and reserve UDP capacity for confirmed flows. Floods that saturate the uplink require upstream filtering.") }}

{{ _("01 / Forward") }}

{{ _("Connections and datagrams.") }}

{{ _("TCP streams and UDP mappings go to a pool of servers. A TLS connection can pass through undecrypted, routed by its server name. QUIC can pass through too. The PROXY protocol carries the address of the client.") }}

{{ _("02 / Terminate and route") }}

{{ _("HTTPS without a second proxy.") }}

{{ _("Sibuna terminates TLS and serves HTTP/1.1, HTTP/2, HTTP/3 and WebSocket. It routes each request by host name, by a wildcard such as *.example.org, and by path. Certificates come from Let's Encrypt or another ACME authority, and a local authority covers internal names.") }}

{{ _("03 / Stay up") }}

{{ _("Change it while it runs.") }}

{{ _("A checked reload applies new routes to new work. Established TCP streams keep their backend. Linux also supports listener handoff during a binary upgrade.") }}

{{ _("04 / Scale out") }}

{{ _("Several nodes, one behaviour.") }}

{{ _("Nodes of a mesh share the sticky table and the limits of a server, and forward a client to the node that owns it. A PostgreSQL database can publish one configuration to every node and roll it back.") }}

{{ _("05 / Protect") }}

{{ _("Ask bots to do the work.") }}

{{ _("A browser challenge adds a cost to automated access, and a signed session lets an admitted visitor return. Rules allow, challenge or deny. The shield checks requests for SQL injection, XSS, path traversal and command injection.") }}

{{ _("06 / Extend and observe") }}

{{ _("See and shape the decisions.") }}

{{ _("Hooks run at the connection and at the request: compiled in, as WebAssembly with a budget, or in a separate process. Metrics, access logs and a console show servers, flows and the reason for each refusal.") }}
