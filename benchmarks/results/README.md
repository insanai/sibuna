# Sibuna Benchmark Results

Machine-readable performance results generated by `sh benchmarks/run-all.sh`. Each run
captures the exact bare-metal execution environment and writes `<date>-<host>.json` and
updates `latest.json`. The book (`docs/book.typ`) and documentation cite numbers exclusively
from `latest.json` dynamically at compile time.

## Evaluation Scope

The benchmark suite measures the six performance-critical subsystems of the web firewall
and anti-crawler daemon:

1. **Proof-of-Work Verification (`pow_verify`):** Native silicon SHA-256 Hashcash evaluation
   vs Go Wazero WebAssembly VM execution of HashX/Argon2id.
2. **Bot Detection (`bot_matcher`):** Multi-string SIMD-ready Aho-Corasick automaton with
   comptime branchless lowercase table vs Go sequential slice matching over 40 signatures.
3. **IP CIDR Classification (`ip_filter`):** Bitwise IPv4 Radix Trie traversal in $O(k)$
   operations vs linear slice scans of `net.IPNet`.
4. **Token Authentication (`token_auth`):** 96-byte compact binary token signed with Ed25519
   and verified on stack vs JSON Web Token (JWT) base64 parsing and reflection map allocation.
5. **Challenge Cache (`challenge_store`):** 16-shard in-memory decay map with atomic `SpinLock`
   (`std.atomic.Value(bool)`) vs Go single `sync.RWMutex` map.
6. **HTTP Request Parsing (`http_parser`):** Zero-copy stack buffer request and cookie parser
   vs Go standard `net/http` request parsing.

## Measurement Environment

- All runs executed in `ReleaseFast` optimization mode on bare-metal silicon.
- 7 independent sample passes are collected per workload.
- Median, min, max, p50, p90, and p99 latencies are recorded.
- Dynamic heap allocations are verified in the hot path ($0$ bytes in Sibuna).
