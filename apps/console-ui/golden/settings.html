Settings

Notifications, retention and response pages.

Notification destinations

At most eight destinations. Webhooks receive a JSON body with an HMAC-SHA256 signature when a secret is set; syslog receives RFC 5424 lines over UDP or framed TCP, selected explicitly below. Secrets are stored sealed and never shown again.

Optional shared secret for the webhook signature (at most 64 bytes).

Events

Denial spike thresholds

A spike is raised when denials in the last 60 seconds exceed both the minimum and the factor times the previous 60 seconds; it re-arms below that threshold.

Retention

Choose retention within the displayed limits. Cleanup deletes older records in bounded batches. A higher value cannot restore deleted history. Rankings also have a fixed 512 MiB quota and may expire sooner.

Response pages

Bounded HTML served to browsers for challenges, denials, rate limits, bans and overload. Placeholders: {{ status }}, {{ reason }}, {{ retry_after }}, {{ request_id }}, {{ node }} and, for the challenge page only, {{ challenge }}. Scripts, external resources, forms and event handlers are refused; the challenge page must contain the solver slot exactly once.
